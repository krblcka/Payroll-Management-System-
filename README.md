# KazHR Portal

## Description
KazHR Portal is a web-based HR and payroll management system designed for companies in Kazakhstan.  
The application allows employers to manage employees, calculate payroll, and generate tax reports. Employees can view their salary details, schedules, and tax breakdown.

## Features
- Employer dashboard with company statistics  
- Employee management (add and view employees)  
- Payroll calculation system (IIT, OPV, OSMS)  
- Payroll history tracking  
- Tax reports generation  
- Employee personal dashboard  
- Payslip and tax breakdown view  
- Work schedule management  

## Tech Stack
- HTML  
- CSS  
- JavaScript (Vanilla JS)  

## Project Structure
- index.html — main UI structure  
- style.css — styles and layout  
- script.js — application logic and data handling  

## How to Run Locally
1. Download or clone the repository  
2. Open index.html in your browser
